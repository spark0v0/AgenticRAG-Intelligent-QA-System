Inter Latin variable font, vendored from @fontsource-variable/inter 5.3.0 (npm registry).

Upstream: https://github.com/rsms/inter
License: SIL Open Font License 1.1; see Inter-OFL.txt.
Only the upright Latin subset is vendored here (48,256 bytes). Chinese uses Noto Sans SC Variable, pinned through `@fontsource-variable/noto-sans-sc` in package.json. Its WOFF2 subsets are selected by CSS unicode-range and served by this application. Both families are licensed under SIL OFL 1.1; the Noto license is also copied to public/fonts for distribution. No external font request is made at runtime. System fonts remain available while fonts load or if a local font request fails.
