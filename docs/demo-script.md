# 3～5 分钟实际操作展示

这里的“展示”指真实业务操作，产品没有演示模式。使用 README 启动项目并确认所选模型可用；准备无敏感信息的新会话，避免公开个人历史或后端凭据。联网或供应方失败时如实展示错误恢复，不更换成模拟答案。

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00～0:40 | 模型供应商页查看配置；打开新增表单并直接保存，点击错误摘要定位字段后取消；编辑已有供应商，展示 Key 留空保留 | Element Plus 校验与业务校验分工；字段错误保留、提交互斥、配置/模型列表/生成状态区分。无需为此操作改动真实凭据 |
| 0:40～1:30 | 选择知识检索，输入“用三点概括本地资料中 AgenticRAG 的核心模块，标注来源” | POST SSE 传递真实增量；阶段进度与回答文本是不同事件 |
| 1:30～2:15 | 点击回答的 `[S1]` 定位证据，再打开运行分析，选择检索节点，查看工具、起止时间并导出 | 仅为后端提供映射的编号生成引用按钮；瀑布来自真实记录，缺失时间不补造 |
| 2:15～2:50 | 追问“用一句话总结”，完成后刷新或切换会话返回 | 多轮上下文、session/run 关联、最终回答与来源持久化 |
| 2:50～3:30 | 发起较长问题，停止生成，检查输入恢复；需要时手动重试 | 前端中断与后端取消分别处理，旧 run 不影响下一轮，不承诺停止计费 |
| 3:30～4:10 | 工具中心搜索 calculator、查看 schema；系统概览查看模型状态 | 已注册、已配置、调用成功含义不同，没有假管理按钮 |
| 4:10～4:40 | 切换窄屏，在运行列表搜索，进入单次详情后返回，再切换深色主题 | 保留搜索与选择；移动端不让列表挤占详情；主题覆盖表单和错误状态 |

备用路径：缺少凭据时展示未配置状态、只读工具/系统页和已有真实历史；网络失败时展示保留输入和手动重试，不宣称当前联调成功。Critic 可能再次生成，解释草稿重置属于新 generation，最终消息来自 completed。

最新截图和验证范围见 `verification.md`。`screenshots/workspace-*.png` 为最新真实配置页面，`real-*` 是前一版本真实证据；`frontend/test-results/evidence/fixture-*.png` 仅供自动化测试，不能作为真实模型回答展示。
