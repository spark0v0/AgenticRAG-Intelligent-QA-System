# AgenticRAG 工作台演示知识库

> 历史归档：演示模式已退役，本文件不再被应用加载或索引。以下为旧版本材料，不代表当前产品行为。

AgenticRAG 的核心组成包括 Router、Planner、Retriever、Generator 与 Critic。
Router 判断问题意图及复杂度，Planner 拆解任务并选择检索策略，Retriever 聚合知识库与工具结果，Generator 生成回答，Critic 通过规则评分决定是否修订。

传统 RAG 常采用固定检索生成流程；AgenticRAG 根据问题类型决定直接回答、检索或先规划再检索。动态流程便于处理复杂问题，也增加了状态管理和异常处理成本。

工作台使用 Vue 3、TypeScript、Pinia 管理消息与运行状态，通过 SSE 接收执行阶段和回答增量。session_id 表示会话，run_id 表示某一轮执行。切换会话不改变事件归属，停止只取消对应运行。

来源追踪保留检索证据与来源编号，执行时间线显示实际调用及起止耗时。Critic 分数属于规则评估参考，不能解释为事实准确率。

这是离线演示知识库。演示回答与增量由本地样例生成，不调用外部模型；网络搜索、实时天气在演示模式不可用。真实模式下需要有效的模型配置及网络。
