# 工具接入与调用

工具中心包含内置工具和可配置 MCP 服务。Tavily 仍通过 HTTPX 直接调用搜索 API；无需改成 MCP 才能使用。

## 添加 MCP 服务

1. 添加服务名称与连接方式。Streamable HTTP 填写完整 MCP 端点（通常以 `/mcp` 结尾）；远程服务要求 HTTPS，本机可使用 HTTP。stdio 填写已安装的可执行程序，以及 JSON 字符串数组形式的启动参数，不执行 shell 拼接。
2. 认证需要 Token 时，在后端 `.env` 中设置环境变量，页面仅填写变量名。stdio 可按名称传入指定变量；不会将整份后端环境传给子进程。修改 `.env` 后重启后端。
3. 保存后点击「连接并发现」。这一步只初始化连接并读取 `tools/list`，不执行工具，也不调用回答模型。
4. 核对工具描述和 Schema，在「试运行」填写 JSON 参数并点击「执行查询」。这会真实调用一次工具，可能消耗服务额度；不自动重试。结果展示返回文本、状态和耗时。
5. 选择需要的只读工具，点击「应用到问答」。使用支持 Function Calling 的 OpenAI 兼容或 DeepSeek 模型，选择「自动」检索范围与检索/深度模式。自动思考模式也可按问题进入工具路径；快速模式不调用工具。

仅支持工具声明 `readOnlyHint: true` 的查询用途，未声明的工具仍可查看但不能启用或试运行。声明由服务提供，工作台无法保证第三方实现确实只读，请只接入可信服务。当前没有 OAuth、旧版 HTTP SSE 传输、写操作或循环自主工具执行。

## 作用范围与状态

- 不启用服务就不会自动调用。没有外部工具时，保持原有低成本规则选择。
- 选择知识库或明确指定 local/web/all 时，严格执行原有资料范围，不追加外部 MCP 工具。
- 支持 Function Calling 的模型产生工具名称与参数；后端依据发现的 JSON Schema 校验参数。缺失或错误的参数不会发送给服务，也不会用 `query/limit` 猜测填充。
- 默认工具选择预算为 5 秒，失败时回到内置工具策略；不支持 Function Calling 的模型跳过外部工具，选择原因记入检索记录。没有实际执行就不记录工具成功。
- 工具注册、连接验证、应用到问答、最近调用是不同状态。成功返回空结果会明确显示无文本证据。
- 每次连接和调用持有独立 SDK 会话，stdio 在操作结束后退出。取消关闭连接/本地子进程，无法保证远程服务已停止计算或计费。
- 停用或修改后阻止后续调用；已发出的调用通过问答「停止生成」或试运行「停止」取消。修改配置或重新发现后，需核对工具并重新应用。
- 外部结果作为非可信证据进入原有引用流程，以 `mcp://` 标识来源，不将其伪装成网页链接。图片、音频等非文本结果暂不转换为证据。

## 存储与扩展

配置默认保存在 Git 忽略的 `data/settings/tools.sqlite3`，可用 `AGENTICRAG_TOOLS` 修改路径。`mcp_servers` 保存设置 JSON、工具 Schema、选择、配置 revision、连接检查和最近调用摘要；不保存环境变量值或试运行正文。首次启动自动建表，重复运行不会重置配置，无需清理现有会话数据库。

最多 12 个服务，每个服务发现最多 80 个工具、启用最多 16 个，全局最多启用 32 个外部工具。连接/调用超时可配置为 3～20 秒。Schema 限制大小并禁止远程引用，避免校验时访问第三方地址。

`ToolSpec.json_schema` 与 `ToolRegistry` 统一适配动态工具。`tools/managed.py` 将 MCP 工具映射为带服务命名空间的稳定标识，避免与内置工具或其他服务重名。调用参数由本次选择结果传递，不放在共享 Retriever 属性上；检索轮次内按工具与参数去重。运行中已调用外部工具时，Critic 仅修订回答，不自动重检索，以免再次消耗服务额度；跳过原因保存在检索记录中。

本地能力示例 `src/mcp/mock_server.py` 已使用官方 SDK，其内容是预置说明，仅用于连接演示，不作为系统能力验证证据。

## 管理接口

以下路径前缀均为 `/api/settings/mcp`。管理仅允许本机访问；写请求要求 `X-Workbench-Request: 1`，并拒绝跨站 Origin。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/`（请求不带末尾斜杠） | 列表 / 保存服务，返回 id |
| PUT / DELETE | `/{id}` | 修改 / 删除连接配置 |
| PATCH | `/{id}` | `{enabled, selected_tools}`，应用或停用工具 |
| POST | `/{id}/discover` | 初始化、分页读取工具，返回 `{ok, message}` |
| POST | `/{id}/call` | `{name, arguments}`，只读试运行，返回标准化 ToolResult |

删除服务只清理配置与工具列表，不删除历史回答或运行记录。检查期间发生修改时使用 revision 拒绝旧结果写回。

## 离线检查

`tests/mcp_fixture.py` 提供测试城市查询、取消夹具和未声明只读的工具，不需要密钥或外网。`tests/test_tool_management.py` 使用临时数据库核对协议、Schema、禁用、恢复、范围隔离和模型参数到实际工具的调用路径。浏览器检查位于 `frontend/tests/browser/tools.spec.ts`，测试数据不进入用户工作区。
