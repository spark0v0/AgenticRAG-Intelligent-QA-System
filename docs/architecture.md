# 系统架构

## 模块职责

Vue 工作台通过 FastAPI 访问会话、模型配置、知识库与运行分析接口。Python 执行层以单次运行为单位组织智能体、工具调用和事件记录。

| 模块 | 职责 |
| --- | --- |
| Router | 结合显式模式、知识库和检索范围决定直接回答、检索或规划路径；明确指令优先走规则 |
| Planner | 复杂请求可使用模型生成并校验结构化检索子问题，数量与超时受限；失败回退至模板 |
| Retriever | 选择工具并执行查询计划，限制并发与轮次，去重，在没有新证据时停止 |
| Generator | 在上下文预算内融合证据与历史，生成回答并维护来源编号 |
| Critic | 检查未知引用、缺少正文引用和证据不足声明，必要时触发受限重检索或修订 |

五类智能体是职责独立的执行模块，不要求每个模块调用模型。编排入口为 `src/core/rag_system.py`，实际使用用户选择的模型；模型层级建议不等于自动切换模型。

## 检索路径

### 用户知识库

`src/knowledge/service.py` 管理资料库、文档、后台任务与片段。TXT / Markdown 按 UTF-8 解析，文本型 PDF 通过 pypdf 提取文字并保留页码。切分保留段落、标题和位置，最大 420 字符、约 60 字符重叠，PDF 片段不跨页。

关键词模式使用 BM25；混合模式通过 FastEmbed 调用 BGE 中文嵌入模型，在 ChromaDB 查询语义候选，再与关键词排名进行 RRF 融合。查询只使用所选知识库、有效指纹和已提交索引版本。生成中的索引、已删除资料和其他库不会进入候选范围。

### 项目资料

未选择用户知识库时，本地路径可检索配置中指定的 README、docs、src 等项目资料。该路径使用 BM25、HashEmbeddings 与 Chroma，适合项目资料查询，不具备 BGE 学习型嵌入的语义能力。环境配置、测试、缓存与截图不参与索引。

### 联网搜索

`src/tools/web_search.py` 使用 HTTPX 异步调用 Tavily Search API，提取标题、URL 与搜索摘要，统一转换为 ToolDocument。默认 basic 搜索、不请求生成答案，按 URL 去重，区分认证、配额、超时和空结果。公开搜索路径使用 Wikipedia 与 DuckDuckGo 即时答案接口，覆盖范围有限。

## 工具扩展

ToolRegistry 负责工具注册、Pydantic 参数校验、超时和标准化 ToolResult。默认策略根据意图和显式范围选工具，可配置模型 Function Calling 选择；当前适配提取工具名称，由后端构造参数，不是通用的循环工具对话框架。

MCP 示例通过本地 stdio 客户端调用示例服务。LangChain Runnable 与 Dify 工具包装位于 `src/integrations/`；外部平台集成需分别验证协议、依赖与配置。

## 运行与事件

- `session_id` 关联对话，`run_id` 标识一次问答，同会话同时只允许一个活动运行。
- 执行事件携带递增 `seq`；节点用 `stage_id`，工具调用用 `call_id`，生成修订用 `generation` 区分。
- 会话页面通过 SSE 接收阶段、来源和回答增量；独立运行分析页面查询持久化记录，并轮询选中的活动运行。
- 节点起止时间与耗时在后端记录，前端按标识归并并绘制时间线和瀑布图。
- Critic 修订通过新的 `answer_start` 替换草稿；最终答案、来源及历史在同一提交中保存。
- 失败和取消保留未完成草稿，客户端不自动重发问题。

## 持久化与资源边界

会话列表按摘要分页；会话内容按稳定游标加载最近 20 轮，旧 JSON 导入、失败与取消记录共同参与分页。详情只读取本页轮次的消息、附件和执行事件。前端复用历史恢复逻辑合并旧页，按消息 ID 和运行/序列号去重，保持当前输入与运行状态；在 DOM 更新前记录可见消息位置，更新后补偿滚动偏移。完整导出仍显式读取全会话。

SQLite 保存业务记录，Chroma 保存检索向量，文件系统保存原文和模型缓存。后台索引使用一个线程和 SQLite 作业队列；重启后未完成索引标记为可重试失败，未开始任务继续排队。

索引先写入新 generation，完成后事务切换；删除先使资料退出检索，再清理文件和向量。历史证据保存快照，查看原文时再确认文档可用性。

服务面向本地单进程运行。模型调用与异步搜索可关闭连接，同步 PDF 解析、嵌入和工具只能在检查点取消；服务端不能保证供应商停止计算或计费。Critic 的规则检查不等于事实准确率。
