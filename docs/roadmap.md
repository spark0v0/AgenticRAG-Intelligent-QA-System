# 后续规划

按实际使用中的问题与规模需求逐步推进。

| 方向 | 当前状态 | 后续工作 |
| --- | --- | --- |
| 知识库格式 | TXT、Markdown、文本型 PDF | 评估 OCR、其他文档格式与解析错误定位 |
| 检索质量 | BGE 与 BM25/RRF 融合 | 建立中文查询样本，根据误召回分析分词与重排收益 |
| 长会话 | 会话历史完整读取 | 消息分页、附件文件化；测量后评估虚拟列表 |
| 任务处理 | SQLite 队列、单索引线程 | 根据负载需求增加并发控制与多进程协调 |
| 工具管理 | 工具列表、协议筛选与 Schema 查看 | 配置持久化、启停和运行配置快照 |
| 模型支持 | OpenAI 兼容、DeepSeek、Ollama、Xinference | 扩展本地供应商的流式与取消适配 |
| 外部集成 | MCP 示例、LangChain Runnable、Dify 包装 | 验证第三方服务兼容性，完善插件打包与配置 |
| 部署 | 本机单用户 | 在提供公网访问前补充认证、访问控制和请求限额 |

知识图谱目前采用配置式关系；图数据库与编辑能力需单独定义数据模型和接口。更换嵌入模型或切分策略时需更新索引指纹并重建，保留原文与历史记录。
